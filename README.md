# AffinityX – Modern AI-Powered Dating Platform

Welcome to **AffinityX**, a groundbreaking platform that redefines online dating with intelligent matching algorithms and AI-driven conversation assistance.

## 🌟 What Makes AffinityX Special?

- **AI-Powered Matching:** Connect with compatible people using advanced algorithms that factor in personality, communication, emotional intelligence, and confidence.
- **Real-Time Chat & Dating Assistant:** Enjoy seamless, secure chats and get instant advice from a built-in AI dating assistant powered by Google Gemini.
- **Beautiful, Responsive Design:** Experience a sleek dark-themed interface, powered by Next.js and Tailwind CSS, optimized for every device.
- **Comprehensive Profiles:** Showcase your interests, skills, and personality through multi-step onboarding and a rich profile gallery.
- **Interactive Dashboard:** Swipe, connect, and chat in a Tinder-style interface with smooth animations and real-time feedback.

## 🏗 Architecture Overview

AffinityX is built as a microservices ecosystem:
- **Match Backend (Go):** Handles user management, matching, chat, and image uploads (PostgreSQL & Cloudinary).
- **AI Server (Node.js):** Powers chatbot features and conversation scoring (MongoDB & Google Gemini API).
- **Client App (Next.js):** Delivers a beautiful, animated user interface with secure JWT authentication.

## 🚀 Features

- **Multi-step Registration:** Capture preferences, skills, and photos for more meaningful connections.
- **Compatibility Scores:** AI evaluates profiles for perfect matches.
- **Match Requests & Responses:** Accept or reject with a click; track all your interactions.
- **Photo Management:** Upload, list, set primary, and delete images easily.
- **Activity Feed:** Stay updated on profile views, matches, and messages.

## 🛠 Developer Friendly

- Clean, modular codebase using Go, Node.js, TypeScript, and modern React.
- Database schemas for PostgreSQL and MongoDB included.
- API endpoints thoroughly documented for rapid integration.
- Environment variables for secure, scalable deployment.
